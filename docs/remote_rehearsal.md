# 远程隔离链路演练

日期：2026-11-15（Asia/Singapore）。本轮真实连接服务器并使用调度器，计算与数据均为合成 fixture。

## 范围

- 客户端为已发布 `0.1.1` 的独立 wheel 环境，产品身份见[发布记录](releases/0.1.1.md)。
- 使用既有 OpenSSH 配置、公钥认证和严格主机校验，完成只读环境及任务状态查询。
- A 节点请求 1 CPU / 3G；准备、成功、预期失败各提交一次，任务时限 5 分钟。
- 私有测试入口只使用 Python 标准库和预先生成的单行 Parquet，不安装或执行 Core。
  每份结果明确标记 synthetic / no_core_execution，身份摘要仅代表测试 fixture。
- 客户端工作目录与服务器测试目录独立；默认连接、运行配置和既有 workspace 保持原状。

## 结果

| 场景 | 观察与结论 |
| --- | --- |
| 认证与准备 | 公钥认证通过；调度准备任务完成，返回的测试入口摘要与本机固定摘要一致 |
| 成功交付 | 任务完成，实际下载与完整合同校验通过，提交 1 行合成结果及最终 commit |
| 幂等 | 重复 collect 和原归档 import 返回相同回执；同一服务实例只下载一次，冻结请求不变 |
| 预期执行失败 | 调度状态 FAILED；客户端保存 SyntheticRehearsalFailure，记录 EXECUTION_FAILED，无成功提交或值 |
| 文件篡改 | 改动下载副本的 Parquet 字节后，因摘要/大小不符被拒绝 |
| 身份替换 | 替换请求并重算包内请求摘要后，仍因不匹配冻结请求被拒绝 |
| 不安全路径 | 增加越界归档成员后，在提交前拒绝 |
| 实际 CLI | jobs 与成功 results 退出 0，预期失败 results 退出 1，无 traceback |

负面包测试仅操作真实下载归档的本机副本，不修改服务器结果。
提交不明的既有本机替身测试 3 项通过；未主动制造真实连接中断或重复远端提交。
