# 客户端安装与运行配置迁移

CLI 使用独立版本线；受管理起点为 `0.1.0`。此前实验版本的数字排序不能代表
安装迁移方向，切换时应显式选择目标工件并保留 workspace。
安装、升级与回退步骤见[安装手册](installation.md)。

## 当前公开范围

公开仓库和客户端安装包只包含界面、本机因子库与配置、请求和通信合同、
SSH 提交查询、结果校验与本机管理。服务器计算引擎、部署、执行和数据适配实现
不随客户端发布或安装。旧工程历史保留在私有历史中，不并入公开仓库起始历史。

## 新任务配置

旧上传运行代码模式已移除。创建或提交新任务前，必须重新运行 `configure-run`，
同时显式提供以下参数：

- `--remote-python`：维护者提供的既有服务器解释器。
- `--data-root`：使用者已获准访问的数据目录。
- `--release-root`：维护者提供的不可变服务版本目录。
- `--release-sha256`：该版本清单的 SHA256。

客户端不推测或自动补全这些服务器值。新任务只上传请求，由既有服务器处理。
配置示例见[服务器运行配置](public_runtime.md)。

## 旧资料与恢复

旧配置和历史结果保留只读兼容；这不表示旧任务能直接重新提交。
旧请求、回执、产物摘要和结果身份不为迁移重写，不自动恢复计算或重复提交。
如需重新计算，应先完成新配置，再创建独立请求，保留旧结果供追溯。

请求/结果协议仍为 `fe-cli-result-v1`，服务清单协议为
`fe-cli-public-release-v1`。协议兼容不等于数值、数据权限或所有节点均已验收。
客户端回退与服务器配置回退分别处理；回退客户端不会改变已提交任务或已有结果。
本说明不宣称正式工件已发布、服务器已部署或真实计算已验收。
