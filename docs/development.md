## 公开客户端与安装发布准备（2026-11-15）

本轮将公开源码范围收敛到客户端：终端界面、CSV 因子库、本机配置、请求冻结、
SSH 提交与查询、下载校验及本机结果管理。公开版不包含后台部署、执行或数据适配实现。
旧工程历史和内部运行证据保留在私有历史中，公开仓库采用独立起始历史。

新任务只上传冻结请求，不再上传运行代码。使用者须配置既有、获准使用的服务器环境，
显式提供 `--remote-python`、`--data-root`、`--release-root` 和 `--release-sha256`。
旧配置和已有结果保留只读兼容；创建或提交新任务前必须迁移运行配置。
本次不重写旧请求、回执或结果身份，也不改变结果数值与有效性合同。

CLI 受管理版本从 `0.1.0` 起步，独立于服务器产品编号。新增 `fe-cli` 命令，
保留 wheel 内的 `fe` 兼容入口；帮助和版本输出随启动入口显示。
固定提交构建器从 Git archive 构建 wheel、sdist、锁定依赖和固定摘要安装器，
生成发布清单与 `SHA256SUMS`，不自动上传或部署。

安装器面向 Linux / WSL、x86_64、glibc >= 2.28，通过 uv 创建 Python 3.12 独立环境。
依赖按摘要校验且只安装 wheel；版本检查成功后切换入口，保留旧环境、配置和 workspace。
步骤及边界见[安装手册](installation.md)，旧安装及运行配置迁移见[迁移说明](core_transition.md)。
