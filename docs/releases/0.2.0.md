## 用户可见变化

- 裸字段和显式 col 均原样提交，不自动改写公式、CSV 或定义指纹；具体字段语义由 Core 校验。
- 授权检查主入口改为 `/status` / `fe-cli --online status`，`setup` 保留兼容别名。
- 首次 init 自动写标准运行配置；已有 CSV、自定义配置及结果保留，损坏文件明确拒绝覆盖。
- 新配置不要求固定 Core SHA，由配套服务器入口在任务启动时校验当前安装并记录实际版本身份。

## 配套与迁移

最后一项需要支持该模式的 Core 服务器启动入口。仅更新客户端无法取消旧入口的固定 SHA 要求；
Core 配套要求作为独立任务 prompt 移交，不随 CLI 安装器上传或安装到服务器。
旧固定 SHA 配置和请求继续严格匹配；如果迁移到当前 Core 模式，可运行 configure-run，
并显式保留所需的自定义路径、节点及运行参数。重复 init 不自动改写既有配置。

旧请求、已提交任务、历史结果和本机回执保持原身份，客户端升级不重算或覆盖历史值。
协议仍为 fe-cli-result-v1 / fe-cli-public-release-v1；新模式成功结果必须提供实际发布摘要、提交和 wheel 身份。
