# fe-cli 0.3.0 发布记录

日期：2026-11-17。状态：发布准备中，尚未确认远端发布或最新安装入口已切换。
源提交、工件摘要、CI 结果及最终发布状态待完成构建和验收后补充。

## 用户可见变化

- 安装器新增 macOS 14+ 的 Apple Silicon（arm64）和 Intel（x86_64）适配；
  macOS 与 Linux 共用客户端源码、`0.3.0` 版本号、通用 wheel 和安装模板。
- macOS 使用系统 `shasum -a 256` 校验工件，以 BSD `mv` 语义切换命令入口；
  保留版本归属校验、安装锁、失败保留环境及无关命令保护。
- Linux 安装范围继续为 x86_64、glibc >=2.28；安装器仍使用 uv 创建 Python 3.12 独立环境。
- 官方 curl 安装入口统一为
  `https://github.com/HKUST-QUANT-SOCIETY/fe-cli/releases/latest/download/install.sh`，
  只提供最新正式版本，不提供版本或渠道选择。实际脚本仍固定版本和工件摘要。
- 历史 Release、标签和附件保留供下载及追溯，但不继续维护或承诺修复；历史正式发布不得覆盖。

## 配套与迁移

客户端升级保留 workspace、因子 CSV、自定义配置、历史结果及旧版本环境；
默认安装目录仍为 XDG 数据目录或 `~/.local/share/fe-cli`，命令入口仍为 `~/.local/bin/fe-cli`，
不迁移已有目录，不改写 shell 配置。已有 uv tool 或源码安装沿用原方式升级。

Core 仍独立发布，不随客户端安装或升级；本次无服务器变更、部署或远程作业提交。
请求/结果与公共发布协议仍为 `fe-cli-result-v1` / `fe-cli-public-release-v1`，
客户端升级不改变既有请求、回执、历史结果身份或数值语义。
内部验收、固定版本部署及运维回滚保留，不作为另一个用户发布渠道。
